# Radio-Communication-Device-Version-8
The RCD 8 (Radio Communication Device Version 8) is small communicator powered by an ESP32. The RCD has an OLED display ,and buttons for user input. It features automatic WiFi connection, SSID and WiFi password memory, NTP time synchronization, morse code communication features, and message memory. It also displays current weather data.
